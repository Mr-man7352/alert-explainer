# models/ (weights are git-ignored; model cards are committed)

- `lgbm/`: `model.txt` (LightGBM booster), `calibrator.joblib`, `meta.json` (classes, features, threshold), `model_card.md`.
- `mlp/`: `model.pt` (PyTorch state dict + config; load with `weights_only=True`), `preprocessor.joblib`
  (quantile transform), `calibrator.joblib`, `meta.json`, `model_card.md`.

Model cards are generated by `uv run ae compare` from `reports/*_metrics.json`.
