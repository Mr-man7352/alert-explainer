Why each mapping:

- **DoS**: Hulk/GoldenEye flood a web server with HTTP requests and slowloris/Slowhttptest hold its connections open: denial of service against a service on one endpoint (Service Exhaustion Flood).
- **DDoS**: LOIC traffic from several sources saturates the target's network capacity (Network Denial of Service, Direct Network Flood).
- **PortScan**: nmap probes many ports to find listening services (Network Service Discovery).
- **BruteForce**: FTP-Patator and SSH-Patator try many passwords against a login service (Brute Force: Password Guessing).
- **WebAttack**: SQL injection and XSS exploit the public web application (Exploit Public-Facing Application); the web brute-force variant guesses its login (Password Guessing).
- **Bot**: Ares bots poll their controller over HTTP (Application Layer Protocol: Web Protocols).
- **Other-rare**: Heartbleed exploits a public-facing TLS service (T1190). Infiltration starts with a victim opening a malicious file (User Execution) and continues with an internal network scan (T1046). Never trained on: alerts are rare and retrieval falls back to embeddings.
